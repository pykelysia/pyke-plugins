# 示例：一次完整的共创设计会话

对 coding agent 说：

> 我要给管理后台做一个「数据源配置」页面。先别写代码——用画板画线框给我看，
> 我会在上面框选批注，改到我们都满意再定稿实现。

## 期望的会话走向

**Agent（遵循 ui-draw skill）：**

1. `setup_board(preset=desktop)` + `show_board` —— 支起 1440×900 画板，帮你打开浏览器
2. 切到**草稿层**，用 1px 灰线打出大关系：左侧 240px 导航、顶部 64px 工具栏、
   中间数据源卡片网格（3×2）、右上角"新建数据源"主按钮位
3. `look_at_board` 自查一眼比例
4. 切到**线稿层**描正稿：导航项矩形+文字、每张卡片的图标占位（椭圆）、
   名称/状态标签/编辑按钮、分页条；`write_text` 写全文案
5. 画完一块就看一眼，再画下一块
6. 告诉你："画好了，你框选想改的地方写条批注，写完在对话里说一声"
7. 等你说"改吧"，再读批注动手

**你（人类）：**

在浏览器里选「📝 批注」工具，框住第三张卡片，写：「这列改成列表视图，卡片太占地方」，
Ctrl+Enter 提交。再框住右上角按钮写：「按钮换到左下」。

**Agent 继续：**

8. 立刻收到两条批注（含区域坐标），`look_at_board(layer=批注)` 对照看一眼
9. 删掉卡片网格、改画列表行布局、移动按钮 → 再 `look_at_board` 全图确认
10. 每条处理完 `resolve_annotation` 标记已解决，画布上批注会变淡
11. 和你确认后 `finalize_design` → 生成 `design/` 设计包（批注不进设计图，但记进 DESIGN.md）

**实施：**

12. Agent 读 `design/DESIGN.md`（每个元素的精确坐标、全部文案、用色）+
    对照 `design.png`，开始写页面代码——不再凭空想象布局。

## 你觉得画得不错，想立刻在代码里对照

- 框选某块区域 → 点「复制选区图」→ 直接 Ctrl+V 粘贴进对话框，agent 就能看到你圈的是哪
- 或点批注条目上的「复制引用」→ 粘贴文字引用（带编号和区域坐标）

## 关掉 ZCode 之后

画板自动存在用户目录（`~/.ui-draw/projects/<项目名>/board.json`），后台服务是常驻的，
关掉会话、关掉所有 agent 都不影响它。下次开会话，agent 一 `inspect_board` 就看到上次的成果，
`show_board` 打开同一个项目地址继续画——批注、图层内容都在。
（撤销历史本身不跨会话保留，这是有意的：新一天的工作从干净的历史开始。）

## 多个项目 / 多个 agent

- 每个项目一块板：`http://127.0.0.1:4680/p/<项目名>/`，根路径 `http://127.0.0.1:4680/` 是项目索引
- 同项目开两个会话 → 画的是同一块板，实时同步
- 不同项目互不干扰

## 其他玩法

- **改现有 UI**：「这是我们现在的设置页（截图 path/to/shot.png），帮我重新设计」
  → agent `paste_reference` 贴到参考层，在旁边画改法
- **放大看细节**：滚轮对着某个输入框放大到 300%，看清 1px 对齐后再画
- **中途搁置**：自动就存了；也可以 `save_board` 另存一份快照
